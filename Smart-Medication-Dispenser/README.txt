# 💊 Smart Medication Dispenser System (Arduino UNO R4)

## 📌 Overview

This project is a smart embedded system designed to improve medication adherence by automating pill dispensing and providing real-time alerts.

---

## ⚙️ Features

* Real-time scheduling using RTC
* Automatic pill dispensing using servo motor
* LED and buzzer alerts
* LCD display
* Push button confirmation

---

## 🛠️ Components

* Arduino UNO R4
* RTC Module
* Servo Motor
* LCD
* Buzzer
* LED
* Push Button

---

## 🚀 How it works

The system checks time every minute and dispenses medication automatically, then alerts the user until confirmation.
